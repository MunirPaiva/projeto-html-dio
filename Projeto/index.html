Apresentação do Curso

Bem-vindo ao nosso curso introdutório de HTML!

Aqui você aprenderá os fundamentos essenciais para construir suas primeiras páginas web, compreendendo desde o uso das ferramentas até a criação de textos, links e listas. O objetivo é apresentar cada recurso de forma simples, prática e direta, permitindo que você desenvolva confiança para escrever seus próprios códigos HTML.

A seguir, você encontrará os tópicos que serão abordados ao longo do curso, cada um com uma breve explicação para guiar sua jornada no desenvolvimento web.

Voltar ao Menu

Ferramentas Utilizadas

Neste tópico, você conhecerá as principais ferramentas utilizadas no curso: o editor de código Visual Studio Code e o navegador Google Chrome. Mesmo assim, você terá liberdade para escolher outras ferramentas com as quais se sentir mais confortável.

Você também aprenderá como abrir e visualizar sua página HTML tanto pelo VS Code quanto diretamente no navegador, garantindo que o conteúdo esteja sendo exibido corretamente.

Voltar ao Menu

Inspetor de Elementos

Aqui você aprenderá a utilizar o Inspetor de Elementos, uma ferramenta poderosa presente nos navegadores modernos. Com ela, será possível visualizar o código HTML da página, entender sua estrutura, testar alterações e até identificar erros. É uma das ferramentas mais importantes para quem deseja aprender desenvolvimento web.

Estrutura Básica do HTML

Neste tópico, você conhecerá a estrutura mínima necessária para qualquer documento HTML.

Falaremos sobre as principais tags como <!DOCTYPE html>, <html>, <head> e <body>, explicando o papel de cada uma na organização do conteúdo exibido na tela.

Falando Sobre Tags

Neste tópico, você entenderá o que são tags HTML, como são escritas e qual é a função de cada uma dentro da página. Veremos exemplos práticos que mostram como elas influenciam a estrutura e a apresentação do conteúdo.

Voltar ao Menu

Atributos das Tags

Você aprenderá o que são atributos HTML e como eles complementam as tags adicionando informações extras ou comportamentos específicos. Entre os atributos ensinados estão id, class, href, src e outros, todos acompanhados de exemplos claros.

Textos

Neste tópico você aprenderá a manipular textos no HTML utilizando tags para criar parágrafos, cabeçalhos e aplicar formatações como negrito, itálico e sublinhado. Esses elementos são fundamentais para deixar o conteúdo mais claro e bem estruturado.

Listas Ordenadas e Não Ordenadas

Neste tópico você aprenderá a criar listas ordenadas com a tag <ol> e listas não ordenadas com <ul>, além de estruturar seus itens utilizando <li>. Listas são ótimas para organizar informações de forma clara e visual.

Links

Aqui você aprenderá a criar links usando a tag <a>. Veremos como redirecionar o usuário para outras páginas, arquivos, sites externos ou até para partes específicas da mesma página. Também explicaremos o uso dos atributos href e target.
