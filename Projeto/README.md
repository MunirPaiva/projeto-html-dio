
# Projeto HTML — Documentação Atualizada

Este projeto foi desenvolvido utilizando exclusivamente **HTML puro**, sem CSS ou JavaScript, com foco em aprendizado e estruturação básica de páginas web.

---

## 📘 Sobre o Projeto

O objetivo deste projeto é demonstrar como criar uma página HTML organizada, contendo:

- Cabeçalho com logotipo
- Menu de navegação
- Diversas seções explicativas
- Rodapé com informações de contato
- Estrutura organizada em pastas
- Conteúdo textual gerado com auxílio do ChatGPT

---

## ⚠ Técnicas Utilizadas e Considerações Importantes

Como o projeto trabalha **apenas com HTML**, sem suporte a CSS, algumas técnicas consideradas obsoletas no HTML5 foram utilizadas para permitir alinhamentos e ajustes visuais.

### Recursos não recomendados, mas utilizados neste projeto:

- Tag `<center>`
- Atributo `align`
- Uso de `<table>` para layout (alinhamento horizontal)
- Uso de `cellspacing` dentro de `<table>`
- Uso de `<br>` para espaçamento vertical

Esses itens ainda funcionam em navegadores modernos, mas **não são boas práticas profissionais**.  
Quando CSS for permitido, essas partes serão facilmente substituídas por:

- Flexbox
- Grid Layout
- Margins e paddings
- Classes e seletores personalizados
